You'll be able to learn how I developed these systems in much more detail in the next section!

Key Systems

Enemy AI State Machine

A state machine with 4 enemy states: Idle, Wandering, Chassing and Stunned.

Hand Animation System

A system composed of real time animation blending for the fingers and pose animations for interactions with different objects

Three Puzzles with Increasing difficulty

The first puzzle the player gets used to the game's controls, the second puzzle the player has to find a code through weighting objects and in the last puzzle the player enters a tiny maze and has to find the exit scriptable objects to hold the data for a weapon
