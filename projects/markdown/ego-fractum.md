## Overview

This game was the final project of my bachelors.

- Enemy AI State Machine
- Hand Animation System
- 3 puzzles
- Narrative System

You'll be able to learn how I developed these systems in much more detail in the next section!

## Key Systems

:::features
- title: Enemy AI State Machine
  description: A state machine with 4 enemy states, Idle, Wandering, Chasing and Stunned.
- title: Hand Animation System
  description: A system composed of real time animation blending for the fingers and pose animations for interactions with different objects
- title: Three Puzzles with Increasing Difficulty
  description: In the first puzzle the player gets used to the game's controls, in the second puzzle the player has to find a code through weighing objects, and in the last puzzle the player enters a tiny maze and has to find the exit
:::
