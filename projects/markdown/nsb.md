## Overview

This game started as a submission to the "Jern Jam 2025 x SciAnts!" Game Jam and then continued as a project by ISEL Game Studios. Throughout development the game has evolved a lot from its main premise, and the current available version was on showcase on a booth at Lisbon Game's Week 2025.
