## Overview

This game was the final project for the course Game Design. Throughout the course I was taught how to concept a game, and then implement it by myself. Some of the systems and tools I ended up implementing into my game were:

- Enemy AI
- Inverse-Kinematic based animation tool in Unity
- Weapon System
- Wave-based Game Manager

You'll be able to learn how I developed these systems in much more detail in the next section!

## Key Systems

:::features
- title: Enemy AI Manager
  description: A manager to control the various enemy AIs in an optimized way
- title: Inverse-Kinematic based animation tool in Unity
  description: This tool lets me easily make re-usable gun animations based on 6 curve graphs on a scriptable object script
- title: Weapon System
  description: A system that lets me quickly create new weapons without having to touch any code, using scriptable objects to hold the data for a weapon
- title: Wave-based Game Manager
  description: Implemented a Game Manager that will make the game's enemies harder as the player progresses through the waves
:::
